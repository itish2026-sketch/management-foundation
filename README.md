# AJKS Foundation

A Django-based web application for AJKS Foundation.

## 🚀 Quick Start Roadmap

Follow these 9 steps to run the project on your local machine.

1. **`git clone <repo-url>`** — Repository download করুন
2. **`cd ajks`** — Folder-এ ঢুকুন
3. **`python -m venv venv`** — Virtual environment তৈরি করুন
4. **`venv\Scripts\Activate.ps1`** (Windows) — Activate করুন
   - Mac/Linux: `source venv/bin/activate`
5. **`pip install -r requirements.txt`** — সব package ইনস্টল করুন
6. **`python manage.py migrate`** — Database setup করুন
7. **`python manage.py createsuperuser`** — Admin account তৈরি করুন (username/password মনে রাখুন)
8. **`python manage.py runserver`** — Server চালু করুন
9. **Browser → http://127.0.0.1:8000/** — Website দেখুন
